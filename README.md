# 🌤 Погодное приложение

Веб-приложение на Flask — показывает погоду и прогноз на 3 дня.

## 🚀 Живой сайт
https://weatherweb-pow3.onrender.com

## 🛠 Технологии
- Python, Flask, requests
- wttr.in (API без ключа)
- Bootstrap 5, Jinja2
- Render (хостинг)

## 📦 Запуск
1. `pip install -r requirements.txt`
2. `python app.py`
3. Открыть `http://127.0.0.1:5000`
